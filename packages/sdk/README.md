# @mayura/sdk

Experimental Mayura authoring facade: `defineTool`, `defineAgent`, `createRuntime`, `invokeTool`, `invokeBatch` and their core contracts. No external runtime dependency or configuration side effect. Provider adapters, native storage, guardrails and other infrastructure are separate explicit imports.

The package is private and unpublished. See the repository's `docs/quickstart.md` and `docs/development-status.md` for the executed example and current limitations.
