# @mayura/server

Experimental authenticated Fetch transport for Mayura's ephemeral runtime plus application-provided human-request and read-only durable-workflow view adapters. It includes opt-in content-free liveness, access-controlled bounded readiness checks and a paginated metadata-only tool catalog. No listener, database, environment credential discovery, durable worker service, workflow mutation or production-hosting claim. See the repository's `docs/specs/http-agent-transport.md` and `docs/specs/workflow-view-transport.md`.
